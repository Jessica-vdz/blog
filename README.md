# Blog

## About the Project

Blog is my first project involving an SQL database backend. The main goal of this project was to gain hands-on experience with backend development and learn how to build a web application that interacts with a database.

The application allows users to read blog posts, while administrators can create new posts and edit existing ones.

I generated the frontend using React and developed the entire backend myself using PHP and SQL. This allowed me to focus on backend logic, database interactions, and connecting the frontend to the backend.

## Features

- **View Posts:** Users can browse and read published blog posts.
- **Create Posts:** Administrators can create new blog posts.
- **Edit Posts:** Administrators can update existing blog posts.
- **Database Integration:** Blog posts are stored and managed using an SQL database.
- **Frontend and Backend:** A React frontend connected to a PHP backend.

## Tech Stack

- **Frontend:** React
- **Backend:** PHP
- **Database:** SQL

## What I Learned

This project was an important step in my development as a programmer. It gave me practical experience with:

- Building a backend using PHP.
- Working with SQL databases and storing data.
- Connecting a frontend to a backend.
- Implementing functionality for creating and editing content.
- Understanding how the different parts of a web application work together.
